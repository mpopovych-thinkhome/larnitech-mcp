Standing user preferences for working with Larnitech through this MCP.

Applied **on top of** the device-type docs: where a preference and the docs
disagree about how to read, write, or present something, the preference
wins. Facts about the equipment itself belong in the docs
(`device-types/<type>.md`), not here — this file is for how you want the
work done.

Served with every `get_docs` call. Starts empty; the agent appends here
when you tell it how you want something handled.
